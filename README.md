# Prolog Medical Expert System

A rule-based expert system built in Prolog that diagnoses potential medical conditions based on user symptoms.

## Technologies Used

- Prolog
- Rule-Based Systems
- Knowledge Representation
- Expert Systems

## Features

- Symptom Questionnaire
- Direct Symptom Input
- Weighted Symptom Matching
- Disease Knowledge Base
- Treatment Recommendations
- Rule-Based Inference Engine

## Diseases Included

- Flu
- Common Cold
- Asthma
- Diabetes
- COVID-19
- Pneumonia
- Migraine
- Hypertension

(and others)

## Concepts Demonstrated

- Knowledge Representation
- Expert Systems
- Logical Programming
- Rule-Based Reasoning
- Decision Support Systems
